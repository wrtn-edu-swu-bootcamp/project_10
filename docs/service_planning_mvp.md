# 서비스 기획안: 스마트 투두 (Smart Todo) - MVP

## 1. 서비스 개요 및 비전
- **서비스명(가칭)**: 스마트 투두 (Smart Todo)
- **비전**: 복잡하게 뒤섞인 할 일들을 쏟아내면, 소요 시간과 마감 기한을 분석해 최적의 실행 순서를 찾아주는 지능형 작업 관리자.
- **핵심 가치**: 
  - **결정 피로 감소**: 무엇을 먼저 할지 고민하는 시간을 AI가 대신 해결.
  - **실행력 극대화**: 당장 시작할 수 있는 작은 일부터 제안하여 심리적 장벽 제거.

## 2. 타겟 사용자 분석
### 2.1. 주 타겟
- **ADHD (주의력 결핍 과잉행동 장애)**: 할 일은 많으나 우선순위를 정하지 못해 시작에 어려움을 겪는 분들.
- **번아웃 위기 직장인**: 업무량이 과부하되어 어떤 것부터 손대야 할지 '인지적 마비' 상태인 분들.
- **시간 관리 초보자**: 체계적인 계획 수립보다 빠른 실행과 정리가 필요한 학생 및 프리랜서.

### 2.2. 페인 포인트 (Pain Points)
- "할 일이 너무 많아서 뭐부터 시작해야 할지 엄두가 안 나요."
- "마감 기한이 제각각이라 우선순위를 짜는 것 자체가 또 다른 업무처럼 느껴져요."
- "계획만 세우다가 에너지를 다 써버려서 정작 실행을 못 해요."

## 3. 핵심 기능 명세 (MVP)
### 3.1. 태스크 덤프 (Task Dump) - 단일 입력 창
- **설계 의도**: 형식이나 구조에 구애받지 않고 생각나는 모든 할 일들을 줄글로 쏟아내게 함.
- **특징**: 로그인 없이 즉시 입력 가능, 자연어 입력 지원.

### 3.2. AI 스마트 프로세서 (Smart Processor) - 자동 추출 및 정렬
- **기능**: 입력된 줄글에서 개별 할 일, 예상 소요 시간, 마감 기한을 자동으로 추출.
- **3가지 핵심 정렬 뷰**:
  1. **Quick Win (소요 시간 짧은 순)**: 5~15분 내외로 끝낼 수 있는 가벼운 일들부터 배치. 빠른 성취감을 통해 업무 몰입 유도.
  2. **Urgency (마감일 촉박한 순)**: 기한이 가장 임박한 순서대로 정렬하여 누락되는 중요한 업무 방지.
  3. **Final Recommended (최종 추천)**: 소요 시간, 마감 기한, 중요도를 종합적으로 계산하여 AI가 제안하는 가장 효율적인 수행 순서.
- **실시간 상태 동기화**: 3가지 정렬 뷰는 동일한 할 일 데이터를 공유함. 어떤 탭에서든 할 일을 완료 처리(체크)하면 다른 모든 탭에서도 즉시 완료된 것으로 표시되어 중복 작업을 방지함.

## 4. 사용자 경험 흐름 (User Flow)
1. **[진입]**: 별도의 가입 없이 메인 페이지 접속.
2. **[입력]**: "오늘 메일 확인하고 2시까지 기획안 제출해야 함. 아 맞다 퇴근길에 우유 사기" 등 할 일을 마구 적음.
3. **[분석]**: '정리하기' 버튼 클릭.
4. **[결과 창]**: 
   - 상단 탭을 통해 '짧은 시간순', '마감 임박순', '추천'으로 정렬된 리스트를 자유롭게 전환하며 확인.
   - 특정 탭에서 할 일을 체크하면 다른 모든 탭에도 즉시 반영되는 통합 상태 관리 제공.
   - 각 항목의 예상 소요 시간과 마감 정보 확인 및 수정 가능.
5. **[실행]**: 체크리스트를 하나씩 완료하며 전체적인 생산성 관리.

## 5. 서비스 운영 정책 및 톤앤매너
- **언어**: 한국어 전용.
- **톤앤매너**:
  - **전체**: 명확함, 간결함, 분석적임, 체계적임.
- **개인정보**: 로그인을 요구하지 않으며, 작성된 내용은 브라우저 세션이 종료되면 휘발됨을 명시하여 부담 없는 사용 환경 제공.
- **플랫폼**: 모바일과 데스크톱 모두 최적화된 반응형 웹.
